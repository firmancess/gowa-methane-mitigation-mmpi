# Gowa Rice-Field Methane Mitigation Potential (MMPI) — Reproducibility Code

This repository contains the publication-stage computational workflow supporting the manuscript **“Remote Sensing-Based Environmental Assessment of Methane Mitigation Potential in Tropical Rice Fields Using Sentinel-1/2 and Multi-Source Data.”**

## Scope

The repository reproduces the downstream analytical workflow from the exported remote-sensing and environmental predictor stacks through final rice-field mapping, calibration, independent map-validation preparation, MMPI reconstruction, sensitivity analysis, CFR ablation, and manuscript figure generation.

MMPI is a **spatial environmental screening index**. It is not a validated methane-emission model and should not be interpreted as a direct estimate of CH4 emissions or percentage emission reduction.

## Repository contents

### Analysis scripts

1. `01_rf_rice_mapping_2026.py`  
   Random Forest rice-field mapping using January–July 2026 Sentinel-1/Sentinel-2 predictors.

2. `02_rf_mask_calibration_2026.py`  
   Final conservative calibration of the RF-derived 10 m rice-field mask. The outside-reference probability threshold is fixed at **0.96**, retained from the finalized development workflow and reported in the manuscript. A threshold sweep is retained only as a diagnostic sensitivity analysis; no undocumented area target is used as a publication-stage selection or validation criterion.

3. `03_rf_internal_class_separability_2026.py`  
   Expanded seed-derived internal RF class-separability assessment. These metrics are internal diagnostics and are not treated as independent final-map accuracy.

4. `04_export_acatama_validation_raster.py`  
   Conversion of the final rice-field raster to the two-class thematic format used in QGIS/AcATaMa.

5. `05_final_mmpi_reproducibility.py`  
   Canonical 30 m MMPI reconstruction using the calibrated 2026 rice-field mask and 2021–2025 environmental predictor stacks. Includes MHSI, AWD proxy, continuous flooding risk, uncertainty, fixed-score and relative-priority classes, correlation analysis, 33-scenario one-at-a-time sensitivity analysis, and no-CFR ablation.

6. `06_generate_manuscript_figures.py`  
   Generation of final manuscript figures at 600 dpi using only the canonical Stage-2 and Stage-5 outputs. Legacy 2024 analysis folders and alternative raster fallbacks are intentionally excluded.

### Validation and reproducibility outputs

- `AcATaMa_stratified_accuracy_assessment.csv`  
  Original AcATaMa stratified area-adjusted accuracy output for the final thematic map.

- `MMPI_FINAL_REPRODUCIBILITY_SUPPLEMENT.xlsx`  
  Reproducibility workbook generated by `05_final_mmpi_reproducibility.py`.

- `requirements.txt`  
  Python dependencies used by the workflow.

## Independent map validation

The final rice-field map was independently assessed using 400 stratified validation samples in QGIS/AcATaMa with high-resolution reference imagery.

Key reported validation results:

- Overall accuracy: **95.50%**
- Rice user's accuracy: **100.00%**
- Rice producer's accuracy: **76.26%**
- Map Rice samples: **58**
- Map Non-rice samples: **342**

The AcATaMa assessment is the primary independent accuracy reference. The RF metrics generated by the internal class-separability script are seed-derived diagnostics only.

## MMPI formulation

The final index uses:

```text
MHSI = 0.42 × Hydrology
     + 0.33 × Soil
     + 0.15 × Climate
     + 0.10 × Topography

MMPI_raw = 0.68 × MHSI
         + 0.32 × AWD_proxy

MMPI = MMPI_raw
     × (1 - 0.25 × CFR / 100)
     × (1 - 0.15 × Uncertainty / 100)
```

Fixed-score MMPI classes are interpretive score intervals and are not empirically calibrated methane-emission or methane-reduction thresholds.

## Main input datasets

The workflow uses derived inputs based on:

- Sentinel-1
- Sentinel-2
- CHIRPS
- ERA5-Land
- SoilGrids
- Copernicus DEM
- JRC Global Surface Water
- 2024 rice-field reference raster
- final calibrated January–July 2026 rice-field mask

The final MMPI environmental predictors represent the **2021–2025** period, whereas January–July 2026 Sentinel data are used for the current rice-field domain.

## Important reproducibility boundary

The public repository currently contains the downstream Python workflow and final validation/reproducibility outputs. The exact Google Earth Engine export scripts that produced the final 2026 RF predictor stack and the final 2021–2025 MMPI predictor stacks are not included in this release because the final successful versions could not be unambiguously recovered from the development notebook.

The external irrigation-area plausibility script is also not included because the exact successful script producing the manuscript's irrigation results was not recoverable from the available development notebook. These workflows should only be added after exact reconstruction and numerical verification against the manuscript results.

No missing workflow is represented as independently reproduced when it has not been verified.

## Environment

Install the required Python packages with:

```bash
pip install -r requirements.txt
```

The scripts were developed for Google Colab / Python workflows using Google Drive paths. The environment variable `MMPI_DRIVE_ROOT` can be used to change the root directory when running in another environment.

## Workflow dependency structure

```text
                         ┌─→ 03_rf_internal_class_separability_2026.py
01_rf_rice_mapping_2026.py
                         └─→ 02_rf_mask_calibration_2026.py
                                   ↓
                         04_export_acatama_validation_raster.py
                                   ↓
                         Independent QGIS/AcATaMa validation

02_rf_mask_calibration_2026.py
        ↓
05_final_mmpi_reproducibility.py
        ↓
06_generate_manuscript_figures.py
```

The map-producing RF fit uses up to **7,000 Rice and 7,000 Non-rice seed samples**.  
The separate internal class-separability assessment uses up to **30,000 samples per class** and is not an independent accuracy assessment of the final map.

## Publication-stage safeguards

- Canonical scripts stop when required inputs are missing rather than silently substituting legacy datasets.
- The Stage-6 figure workflow reads only the verified Stage-5 reproducibility rasters and the exact final Stage-2 rice mask.
- The original AcATaMa output is included separately from the seed-derived RF internal diagnostics.
- The final MMPI reproducibility workbook was generated by the verified Stage-5 rerun and reproduces manuscript values to rounding precision.
